# The scattering section derived from the HHM Hamiltonian (arXiv:1801.08988)

**Model:** J. Hutchinson, J. E. Hirsch, F. Marsiglio, *Enhancement of superconducting Tc
due to the spin-orbit interaction*, arXiv:1801.08988 (2018).  Equation numbers "(HHM n)"
refer to that paper.  This file shows, step by step, that every ingredient of the
corrected W/W_N computation (`project/ultrasonic/`) comes from that Hamiltonian, and what
the only external additions are (the ultrasound perturbation and Fermi's golden rule,
which are not part of HHM — HHM stops at thermodynamics/Tc/gap).

## 1  The Hamiltonian (HHM Eqs. 1–7, 13–14)

Real space, square lattice, ⟨ij⟩ nearest neighbours:

    H = H_Mod + H_SO - mu * sum_i,sg n_i,sg ,

    H_Mod = -t sum_<ij>,sg ( c+_i,sg c_j,sg + h.c. )                       (HHM 1)
            + U sum_i n_i,up n_i,dn                                        (HHM 2)
            + Dt sum_<ij>,sg ( c+_i,sg c_j,sg + h.c. )( n_i,-sg + n_j,-sg )
    H_SO  = i V_SO sum_i,a,b ( c+_i,a sx_ab c_i+yhat,b
                             - c+_i,a sy_ab c_i+xhat,b ) + h.c.            (HHM 7)

t = hopping, U = on-site Hubbard interaction (attractive U<0 or repulsive U>0),
Dt = the *correlated hopping* of the dynamic Hubbard model (generated by the
Lang–Firsov transformation, HHM Eqs. 8–12: Dt/t = S(1-S), S = exp(-g^2/2)),
V_SO = Rashba coupling.  The correlated hopping also dresses the Rashba term
(HHM 13) — this is what produces the cross-term in the pairing kernel below.

Fourier-transformed reduced BCS Hamiltonian (HHM 14):

    eps_k = -2t (cos kx + cos ky)
    V^0(k,k')   = U - 2(Dt/t)(eps_k + eps_k')            (singlet pairing vertex)
    V^R_ab(k)~  = 2 V_SO (Dt/t)( sin kx sy_ab + sin ky sx_ab )   (SOC x Dt cross term)

## 2  Helicity (Rashba) basis (HHM Eqs. 15–20)

Diagonalising the non-interacting part:

    eps_ks = eps_k - 2 s V_SO sqrt( sin^2 kx + sin^2 ky ),     s = +1, -1   (HHM 15)
    c+_ks  = ( c+_k,up + s e^{i th(k)} c+_k,dn ) / sqrt(2),
    e^{i th(k)} = ( sin ky - i sin kx ) / sqrt( sin^2 kx + sin^2 ky )       (HHM 16–17)

s is the **helicity** — the band index of the normal state.  Keeping only intraband
(time-reversed) pairs gives the effective Hamiltonian (HHM 19) with kernel (HHM 20)

    V_ss'(k,k') = s' e^{i th(k')} s e^{-i th(k)}
                  [ U + 8 Dt (s_k + s_k')
                    + 4 V_SO (Dt/t) ( s' sqrt(sin^2 k'x + sin^2 k'y)
                                    + s  sqrt(sin^2 kx  + sin^2 ky ) ) ]    (HHM 20)

with s_k = (cos kx + cos ky)/2.  **This kernel, term by term, is exactly what
`sc_params/gap_equations.py::make_residual` uses** (U + 8Dt s_k + 4(Dt/t)V_SO s'|sin k|),
which is why my stage-1 reproduces the printed Tc, D0, DS of the paper to 4 decimals.

## 3  Mean field, Bogoliubov quasiparticles (HHM Eqs. 21–27)

Pairing field b_ks = s e^{i th(k)} <c_-k,s c_k,s>; gap Delta_ks = s e^{-i th_k} Dbar_ks,
where **Dbar_ks is real** (trivial irrep of D8) and the phase s e^{-i th_k} is the
Rashba gauge factor (HHM 22).  Bogoliubov transformation (HHM 23)

    c_ks = u*_ks alpha_ks - s e^{-i th(k)} v_ks alpha+_-ks

with (HHM 24–26), xi_ks = eps_ks - mu:

    |u_ks|^2 = 1/2 (1 + xi_ks/E_ks),   |v_ks|^2 = 1/2 (1 - xi_ks/E_ks),
    u_ks v*_ks = - Dbar*_ks / (2 E_ks),
    E_ks = sqrt( xi_ks^2 + |Delta_ks|^2 ) = sqrt( xi_ks^2 + Dbar_ks^2 ).

These are the quasiparticles that the scattering section scatters.  Note the minus sign
in u v* = -Dbar/(2E): it is what fixes the sign of the Delta Delta' term in the
coherence factor (Section 6).

## 4  The gap ansatz — why the gap is linear in the band energy (HHM Eqs. 31–37)

Self-consistency with kernel (HHM 20) fixes the ansatz

    Dbar_ks = D0 + Ds s_k + D(x-y) s sqrt(sin^2 kx + sin^2 ky)              (HHM 31)
    D(x-y)  = (V_SO/2t) Ds                                                  (HHM 35)

    =>  Dbar_ks = D0 - (Ds/4t) eps_ks                                       (HHM 36–37)

i.e. the HHM order parameter is a **linear function of the one-electron band energy**:
Dbar(eps) = D0 - b eps with b = Ds/(4t) = DS/(4t) in my notation.  Everything
non-BCS in my scattering algebra comes from this single line:

    E(eps)^2 = (eps - mu)^2 + (D0 - b eps)^2
             = (1 + b^2)(eps - eps*)^2 + Emin^2,
    kappa = sqrt(1 + b^2),  eps* = (mu + b D0)/(1 + b^2),  Emin = |D0 - b mu|/kappa.

For Ds = 0 (b = 0) this collapses to the textbook BCS form E^2 = xi^2 + D0^2.

Gap and number equations solved at stage 1 (HHM 32–34, 38):

    D0 = -(1/2N) sum_k's' ( U + 8 Dt s_k' + 4(Dt/t)V_SO s' |sin k'| ) g(E) Dbar
    Ds = -(1/2N) sum_k's' 8 Dt g(E) Dbar
    n  = 1 - (1/2N) sum_k's' (xi/E) tanh(beta E/2),
    g(E) = (1 - 2f(E))/(2E) = tanh(beta E/2)/(2E)

with the repository's convention D0(T) = phi(T) D0(0), Ds(T) = phi(T) Ds(0),
Delta_eff(T) = phi(T) Delta_eff(0) (both amplitudes scale rigidly), and mu(T) from the
number equation at each T (`ultrasonic/physics_ua.py::SCState`, `solve_mu`).

## 5  The perturbation — the only input NOT contained in HHM

HHM computes thermodynamics only.  The ultrasound coupling is the standard
deformation-potential perturbation of your paper (arXiv:2607.02812): a sound wave of
frequency omega and q -> 0 modulates the hopping (strain), hence couples to the particle
density / kinetic energy,

    H'(t) = B sum_q ( b_q + b+_-q ) rho_q ,     rho_q = sum_k,sg c+_{k+q,sg} c_k,sg .

In the helicity basis, rho_q at q -> 0 is diagonal in s (intraband); interband matrix
elements are O(q) and dropped.  So the vertex does not flip helicity and carries no
spin structure — this is the **Case I (eta = +1)** channel of your paper's classification
(the anomalous terms entering with relative sign eta = +1; eta = -1 would be Case II).

## 6  From the vertex to the coherence factor (the algebra, in full)

Insert the Bogoliubov transformation (HHM 23) into rho.  The density vertex decomposes
into a normal part (alpha+ alpha) and an anomalous part (alpha+ alpha+ and alpha alpha):

    c+_k c_k  ->  u_k^2 alpha+_k alpha_k - v_k^2 alpha_-k alpha+_-k
                  + u_k v_k ( alpha+_k alpha+_-k + alpha_-k alpha_k )   (schematic, one s)

**Scattering** (alpha+_k' alpha_k, absorbing one phonon, E' = E + hw): the amplitude is
the sum of the two ways the vertex can act — direct (u u') and exchange through the
anomalous piece (eta v v'), i.e. M_scat = u u' - eta v v'.  Squaring with the HHM
coefficients (real u, v, real Dbar; the gauge phases s e^{-i th} cancel between
|Delta_ks|^2 and the u,v products):

    M_scat^2 = u^2 u'^2 + v^2 v'^2 - 2 eta (u v)(u' v')
             = 1/4 (1 + xi/E)(1 + xi'/E') + 1/4 (1 - xi/E)(1 - xi'/E')
               - 2 eta ( -Dbar/2E )( -Dbar'/2E' )
             = 1/2 [ 1 + ( xi xi' - eta Dbar Dbar' ) / (E E') ].

For eta = +1:

    C_I(E, xi; E', xi') = 1/2 [ 1 + ( xi xi' - Dbar Dbar' )/(E E') ]        (eq. 1)

This is the coherence factor used throughout `absorption.py` (variant `a_signed`).
Every quantity in it is a function of the band energy alone — xi = eps - mu,
Dbar = D0 - b eps, E = E(eps) — so at fixed (E, E') it depends only on the two branch
labels (sigma, sigma'), not on the helicities (s, s') (Section 7).

**Pair creation** (alpha+_k alpha+_k', E + E' = hw): amplitude M_pair = u v' + eta v u':

    M_pair^2 = u^2 v'^2 + v^2 u'^2 + 2 eta (u v)(u' v')
             = 1/2 [ 1 - ( xi xi' - eta Dbar Dbar' )/(E E') ] = 1 - C_I .

so M_scat^2 + M_pair^2 = 1 identically (verified numerically to 1e-16 in
`validate_ua.py`).  The sign of xi xi' must be kept: replacing xi xi' by |xi||xi'|
(variant b) or by -|xi||xi'| ... (variant c, the paper's final combination) breaks
(1) — in the BCS limit Ds->0 they no longer reduce to the branch projectors and produce
W/W_N > 1 (up to 1.97 at Delta -> 0), which is unphysical for a scattering-only channel.

## 7  Fermi's golden rule and the thermal factors

Power absorbed per unit volume from the sound field:

    W = (2 pi/hbar) sum_{i->f} |<f|H'|i>|^2 delta(E_f - E_i) x (thermal occupations).

Scattering channel (one quasiparticle in, one out):

    W = 2 pi B^2 omega sum_{k s} sum_{k' s'} C_I [f(E) - f(E')] delta(E' - E - hbar w)

the thermal factor being f(E)[1-f(E')] - f(E')[1-f(E)] = f(E) - f(E') (absorption minus
stimulated re-emission).  **Energy conservation is imposed on the quasiparticle energies
E, E' of (HHM 26)** — not on the band energies eps — because the delta function comes
from the time integral of the phonon field in the quasiparticle (alpha) representation.
Misplacing it on eps was one of the paper's defects (erratum E1).

Pair channel:

    W_p = 2 pi B^2 omega sum ... (1 - C_I) [1 - f(E) - f(E')] delta(E + E' - hbar w),

nonzero only for hbar w > 2 Emin(T).

## 7A  The pair-creation channel in detail (from the same HHM Hamiltonian)

**Where it comes from.**  It is not an extra interaction — it is the *anomalous part of
the very same density vertex* rho_q of Section 5, after the HHM Bogoliubov transformation
(HHM 23).  Expand one helicity band (suppressing s and writing k' = k+q):

    c+_k' c_k = u_k' u*_k alpha+_k' alpha_k            (normal:   scatters quasiparticles)
              - s e^{+i th_k'} v*_k' u*_k alpha_-k' alpha_k
              - s e^{-i th_k}  u_k' v_k  alpha+_k' alpha+_-k   (anomalous: CREATES a pair)
              + v*_k' v_k alpha_-k' alpha+_-k + ...

HHM's own mean-field decomposition names this operator: c_-ks c_ks = s e^{-i th(k)} b_ks
+ delta_c_ks (text below HHM Eq. 21), with b_ks = u*_ks v_ks (2<alpha+_ks alpha_ks> - 1)
(HHM 29).  The ultrasound vertex couples to exactly those pair fluctuations delta_c:
the coefficient of alpha+ alpha+ is proportional to u v = -Dbar/(2E) (HHM 26), i.e. to
**Delta_ks/(2 E_ks)** — it vanishes identically in the normal state.  Pair creation is
therefore a purely superconducting absorption channel: one phonon of energy hbar w breaks
one Cooper pair of the HHM condensate into two Bogoliubov quasiparticles.

**The final state.**  The created quasiparticles are (k's, -k s) with k' - (-k) = q ~ 0:
an Anderson time-reversed pair *within the same helicity band* — precisely the pairing
structure HHM argues for in Sec. II (intraband pairing; an interband pair would carry
finite total momentum, "akin to FFLO", and is excluded at zero field).  Note eps_{-k,s} =
eps_{k,s} and Dbar_{-k,s} = Dbar_{k,s} (both even in k), so the two members sit on the
same dispersion; at finite q the pair members scan the energy shell independently.

**Amplitude and coherence factor.**  The two time-orderings of the anomalous vertex give

    M_pair = u v' + eta v u'   (eta = +1, Case I),

    M_pair^2 = u^2 v'^2 + v^2 u'^2 + 2 eta (u v)(u' v')
             = 1/4 (1 + xi/E)(1 - xi'/E') + 1/4 (1 - xi/E)(1 + xi'/E')
               + 2 eta (-Dbar/2E)(-Dbar'/2E')
             = 1/2 [ 1 - ( xi xi' - eta Dbar Dbar' )/(E E') ]  =  1 - C_I .

The HHM gauge phases s e^{∓i th_k} (HHM 22) appear in the coefficients but cancel in
|M_pair|^2 — the local-in-k phase factor of the Rashba gauge has no effect on any rate;
only the *real* Dbar(eps) = D0 - (Ds/4t) eps of HHM Eqs. (36–37) enters.  Completeness:
M_scat^2 + M_pair^2 = 1 for every (E, xi; E', xi') — verified numerically to 1e-16.

**Golden rule.**  Absorption of one phonon, creation of two quasiparticles with
E + E' = hbar w:

    W_p = 2 pi B^2 w sum_{sigma,sigma'} INT dE nu_sigma(E) nu_sigma'(hbar w - E)
            x (1 - C_I)(E, hbar w - E) [ (1-f(E))(1-f(E')) - f(E) f(E') ]
            delta(E + E' - hbar w)
        = 2 pi B^2 w sum_{sigma,sigma'} INT dE nu_sigma nu_sigma' (1 - C_I) [1 - f(E) - f(E')]

The thermal factor is creation minus the inverse process (two quasiparticles
recombining into one phonon): it equals 1 at T = 0 and closes to 0 as both occupations
approach 1/2 near Tc.

**Threshold — HHM-specific.**  Both quasiparticles need E, E' >= Emin, where the HHM
epsilon-linear gap puts the minimum of E(eps) at eps* (not at mu) with value

    Emin(T) = |D0(T) - b mu(T)| / kappa ,     b = Ds/(4t),  kappa = sqrt(1+b^2).

So the channel opens at **hbar w > 2 Emin(T)** — neither 2 D0(T) nor 2 Delta_eff(T).
Only in the BCS limit Ds -> 0 does Emin -> D0 and the textbook threshold hbar w > 2 Delta
return.  This is erratum E4: the paper's window 2 Delta_eff > hbar w is stricter than the
true threshold; inside it W_p = 0 identically (so scattering-only is the complete answer
there), but every neighbourhood of Tc lies beyond it.  Master set (hbar w = 0.7t):
true threshold at T/Tc = 0.820 / 0.912 / 0.975 (V_SO = 0 / 0.4082 / 0.8) vs the paper's
cut at 0.740 / 0.840 / 0.936.

**Phase-space convention.**  The two energies are integrated independently over the shell
E in [Emin, min(hbar w/2, cutoffs)], E' = hbar w - E, with per-channel band cutoffs
E_max(sigma) from |eps_sigma(E)| <= W_band.  This is the standard ultrasound convention
(the q -> 0 limit taken after the thermodynamic limit; strain couples to the continuum of
pair states with vanishing total momentum).  It is *validated*, not assumed: in the
Delta -> 0 limit this W_p plus the scattering W reproduces the normal-state golden rule
W_N to 100.0000 % (test T1), and above the true threshold the sum rule

    C_I + C_pair = 1       (per quasiparticle pair)

holds exactly; the two channels live on different sheets (E'-E=hw vs E+E'=hw) with different
thermal weights, so NO identity with a single normal-state reference follows (the previously
printed (W+W_p)/W_N = 1 is withdrawn, REPORT App. A2).  At Delta->0 the measures coincide and
(S_sc+S_pair)/S_N = 100.0000 % (T1).  Spectral weight merely migrates from the scattering channel into the
creation channel as the gap opens.  (A strictly "vertical" E = E' = hbar w/2 prescription
would violate this sum rule badly.)

**BCS sanity check.**  For Ds = 0: 1 - C_I -> 1/2[1 - (xi xi' - D0^2)/(E E')] -> D0^2/(E E')
— the Mattis–Bardeen pair-breaking coherence factor of textbooks.  With the HHM gap the
D0^2 is replaced by Dbar(eps) Dbar(eps') = (D0 - b eps)(D0 - b eps'), and the signed
xi xi' term keeps the branch (sigma, sigma') structure.

**Diagnostic.**  Only the signed variant (a) satisfies the sum rule.  With the |xi||xi'|
variant (b), the paper's combination (c), or the textbook-static (d), W + W_p *overshoots*
W_N at Delta -> 0 (1.0924 / 1.3386 / 1.9874 respectively) — they create spectral weight
out of nothing.  This is an independent proof (besides the Delta -> 0 projector limit)
that eq. (1) with the sign of xi xi' kept is the coherence factor belonging to this
Hamiltonian.

## 8  From the (k, s) sums to the energy integral with both branches sigma

The k-sum at fixed E must invert E(eps)^2 = kappa^2 (eps - eps*)^2 + Emin^2 — a quadratic,
hence **two band energies share every quasiparticle energy E > Emin**:

    ell      = sqrt(E^2 - Emin^2)
    eps_sigma(E) = eps* + sigma ell/kappa ,      sigma = +1, -1
    xi_sigma(E)  = eps_sigma - mu ,   Dbar_sigma(E) = D0 - b eps_sigma

sigma = +1 is the particle-like root (xi > 0 away from eps*), sigma = -1 the hole-like
root; in the BCS limit (Ds = 0: kappa = 1, eps* = mu, Emin = D0) they reduce to the
textbook xi = sigma sqrt(E^2 - D0^2) — sigma *is* the sign of xi.  Jacobian:
|d eps_sigma/dE| = E/(kappa ell), so the branch DOS

    nu_sigma(E) dE = sum_s N_s( eps_sigma(E) ) * E/(kappa ell) dE ,
and the substitution ell = sqrt(E^2 - Emin^2) removes the square-root singularity:
nu_sigma dE = N(eps_sigma) d ell / kappa  (this is the quadrature used in `absorption.py`).

Because C_I depends only on (sigma, sigma'), the helicity sum collapses into the total
DOS N(eps) = sum_s N_s(eps) of HHM Eq. (18):

    W = 2 pi B^2 omega sum_{sigma,sigma'} INT dE N(eps_sigma(E)) N(eps_sigma'(E'))
          x (E/kappa ell)(E'/kappa ell') C_I [f(E) - f(E')]

with per-channel upper limits from the exact band support |eps| <= W_band,
W_band = 4t sqrt(1 + V_SO^2/2t^2) — the HHM band minimum E_min = -4t sqrt(1 + V_SO^2/(2t^2))
(HHM Sec. II; my `kgrid_ua.band_edge` minimises the same dispersion exactly).  At
hbar w = 0.7t the channels (+1,+1) and (-1,+1) are kinematically empty (their windows
close), which `absorption.py` reports per channel.

**Measure note (correction of 2026-10-15).**  In the double-density integrand
INT dE nu_sigma(E) nu_sigma'(E') C [f-f'] only ONE of the two DOS factors absorbs dE -> d ell;
the final-state density stays per unit E': nu_sigma'(E') = N(eps_sigma'(E')) E'/(kappa ell').
Writing N/kappa for both weights the integrand by ell'/E' -- the defect that the s-wave
cross-check against Levy 1963 (`levy1963_check.py`, test T5) exposed.  With the corrected
measure the omega->0 limit reproduces Levy's alpha_s/alpha_n = 2 f(eps_0(T)) to 3e-6, the
lattice cross-check improves to <=1.6 % at finite Delta, and the same correction applies to
the pair-creation channel of Section 7A.

## 9  The normal reference W_N — same Hamiltonian, Delta -> 0

Setting D0 = Ds = 0 in the SAME model (E -> |eps - mu_N|, C_I -> delta_{sigma sigma'},
nu -> N), the scattering integral becomes the golden-rule normal-state absorption

    W_N = 2 pi B^2 omega INT dE N(E) N(E + hbar w) [f_N(E) - f_N(E + hbar w)],

with N the HHM DOS (Eq. 18) of the two Rashba bands and f_N at the normal-state chemical
potential mu_N(T) from the same number equation.  The prefactors 2 pi B^2 omega cancel in

    W/W_N = S_sc / S_N ,

so the ratio is free of the deformation-potential constant B and of any k-sum
normalisation — but it is NOT free of the DOS: the band structure of HHM Eqs. (15)/(18)
enters through N(eps_sigma(E)) and sets the Tc-limit values R(hw,Tc) < 1.

helicity bands (15), correlated-hopping kernel (20), the energy-linear gap (36–37), the

coherence factor that follows from the HHM u,v coefficients — eq. (1) above.
